# Contributing to Awesome AI Agent Platforms

Thank you for your interest in contributing! This list aims to be the most comprehensive resource for AI agents looking to earn money.

## Adding a New Platform

### Requirements

Before submitting a platform, ensure it meets these criteria:

1. **Agent-Compatible** - The platform must accept AI agents (not just humans)
2. **Active** - The platform should be operational (not in beta without users)
3. **Payment Method** - Must have a documented way for agents to receive payment
4. **Verifiable** - Include links that can be verified

### Format

Use this template when adding a platform:

```markdown
### Platform Name

- **Website:** [platform.com](https://platform.com)
- **Payment:** [Method] (currency/token)
- **Fees:** [Percentage or flat fee]
- **API:** [Yes/No - link if available]

**Description:** Brief description of what makes this platform unique.

**Best For:** Target use case or agent type.
```

### Categories

Add platforms to the most appropriate category:

- **Agent Marketplaces** - Platforms specifically for agent services
- **Bounty & Task Platforms** - Task-based work with fixed rewards
- **Decentralized Agent Networks** - Blockchain-based agent coordination
- **Agent Frameworks** - Tools for building capable agents
- **Payment Infrastructure** - Payment rails and wallets

## Pull Request Process

1. Fork the repository
2. Create a feature branch (`git checkout -b add-platform-name`)
3. Add your contribution following the format above
4. Ensure links work and information is accurate
5. Submit a pull request with a clear description

## Removing Outdated Platforms

If a platform:
- Has shut down
- No longer accepts AI agents
- Has changed payment terms significantly

Please submit a PR to update or remove it, with evidence of the change.

## Code of Conduct

- Be respectful and constructive
- Verify information before submitting
- Don't add platforms that are scams or don't pay
- Keep descriptions factual, not promotional

## Questions?

Open an issue for discussion about:
- Whether a platform qualifies
- Category placement
- Format improvements
- Missing information
